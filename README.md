# ChatItemSprite

**ChatItemSprite** is a lightweight Paper plugin that displays items in Minecraft chat.<br>
Unlike other chat item plugins, it displays an item sprite before the item name, and the item name is localized based on each player's client language.

*The sprite feature can be disabled in `config.yml` if desired.*

## Features
- Display vanilla item in chat **with sprites**!
- - Configurable display sprites
- - You can remove the sprite from chat as you want
- Localized display item names
- Supports [InteractiveChat](https://github.com/LOOHP/InteractiveChat)
- Supports custom item plugins (currently ItemsAdder, Oraxen, Nexo, CraftEngine)
- Optional hover information
- Lightweight and dependency-free
- Easy-to-modify chat format with LuckPerms

## Requirements
- [**Paper** (from PaperMC)](https://papermc.io/)
- Minecraft 26.2
- Java 25
- **No plugins required!**

### Recommended
- LuckPerms: for chat format (not item, whole line)

### Supported Plugin (Custom Item Plugins)
- Chat Plugins
- - InteractiveChat
- Custom Item Plugins _(you need to add your sprite manually for custom items)_
- - ItemsAdder
- - Oraxen
- - Nexo _(Not Tested)_
- - CraftEngine

## (🇰🇷 한국어)

**ChatItemSprite**는 채팅에 아이템을 표시해 주는 가벼운 Paper 플러그인입니다.<br>
다른 플러그인과 다르게 아이템 이름 앞에 아이템 스프라이트를 표시해주며, 아이템 이름이 사용자 언어에 맞게 출력됩니다.

(스프라이트 기능은 `config.yml`에서 끌 수 있습니다!)

## 주요 기능

* 채팅에 아이템을 **스프라이트와 함께** 표시
* * 원한다면 스프라이트를 제외할 수 있습니다
* * Config로 사용자 지정 스프라이트 설정 가능
* 바닐라 아이템 이름이 사용자 설정 언어에 맞게 현지화
* [InteractiveChat](https://github.com/LOOHP/InteractiveChat) 지원
* 커스텀 아이템 플러그인 (ItemsAdder, Oraxen, Nexo, CraftEngine) 지원
* 지정 가능한 정보 호버링
* 빠르게/필요 플러그인 없음
* LuckPerms 수식어 지원
